🔧 BƯỚC 2: IMPORT MACRO VÀO EXCEL (CHẠY TRÊN WINDOWS)
================================================================================

2.1. Mở file "Quan_Ly_Quet_Xe.xlsx" bằng Excel
     ⚠️ Quan trọng: Phải dùng Microsoft Excel trên Windows

2.2. Bấm Alt + F11 để mở Visual Basic Editor
     Hoặc: Vào Developer → Visual Basic (nếu không thấy tab Developer, đọc mục 2.2a)

2.2a. Nếu không thấy tab Developer:
      - File → Options (Tuỳ chọn)
      - Customize Ribbon (Tuỳ chỉnh Ribbon)
      - Đánh dấu ✓ Developer
      - Bấm OK

2.3. Trong VBA Editor:
     - Bên trái: Project Explorer, chọn "VBAProject (Quan_Ly_Quet_Xe)"
     - Click phải → Insert → Module (Chèn → Module)
     - Một sheet "Module1" sẽ mở ở bên phải

2.4. Mở file "VBA_Code_QuetXe.bas" bằng Notepad:
     - Chọn tất cả code (Ctrl+A)
     - Copy (Ctrl+C)

2.5. Quay lại VBA Editor:
     - Click vào sheet Module1 (bên phải)
     - Paste code (Ctrl+V)
     - Đóng VBA Editor (Alt+F4 hoặc click X)

2.6. Excel sẽ hỏi: "Save changes to project?"
     - Bấm "Save" hoặc "Yes"

2.7. Save file dưới dạng MACRO-ENABLED:
     - File → Save As (Lưu As)
     - Tên file: Quan_Ly_Quet_Xe
     - File type: Excel Macro-Enabled Workbook (*.xlsm)
     - Bấm Save

✅ XONG! File .xlsm đã sẵn sàng với macro


📊 BƯỚC 3: SỬ DỤNG FILE EXCEL
================================================================================

KHI MỞ FILE LẦN ĐẦU:
- Excel hỏi: "Enable Macros?" (Bật Macro?)
- Bấm "Enable Macros" (Bật)
- Một cửa sổ thông báo sẽ hiển thị

SHEET QUÉT XE:
└─ Dòng 1 (tiêu đề): Mã Xe | Thời Gian Quét | Thời Gian Quay Vòng | Giờ | Ghi Chú | Xóa

CỘT A (MÃ XE):
- Nhập mã xe (VD: A001, B002, v.v.)
- Macro tự động:
  • Ghi thời gian quét vào cột B (định dạng: dd/mm/yyyy hh:mm:ss)
  • Tính thời gian quay vòng (so với lần quét trước của xe này)
  • Tô vàng nếu thời gian quay vòng >= 16 giờ

CỘT B (THỜI GIAN QUÉT):
- Tự động ghi Now() - không nhập tay

CỘT C (THỜI GIAN QUAY VÒNG):
- Hiển thị dạng: 34H 00M (34 giờ 0 phút)
- Tự động tính

CỘT D (GIỜ):
- Hiển thị dạng số: 34.0 H
- Tự động tính

CỘT E (GHI CHÚ):
- Nhập: bẩn / ban / ko sạch / không sạch
- Hoặc bất kỳ ghi chú nào khác

CỘT F (XÓA):
- Nhập X để đánh dấu xóa dòng
- Macro sẽ hỏi xác nhận
- Bấm Yes → dòng A:F bị xóa + xóa border


📈 SHEET TỔNG HỢP:
================================================================================

Chạy macro để cập nhật:
1. Bấm Alt + F8 (hoặc Developer → Macros)
2. Chọn "CapNhatTongHop_Ngay"
3. Bấm Run

Kết quả:
- Tổng hợp tất cả xe bẩn từ Sheet QuetXe
- Các cột:
  • A: Số Xe
  • B: Lần Bẩn (số thứ tự: 1, 2, 3...)
  • C: Ngày Bắt Đầu (lần bẩn trước)
  • D: Ngày Bẩn Vệ Sinh (ngày hiện tại)
  • E: Số Ngày Quay Vòng (VD: 3 ngày)
  • F: Trung Bình (chỉ hiển thị dòng đầu của mỗi xe)

Ví dụ:
  Xe A, Lần 1: 29/09 → 02/10 = 3 ngày (Trung bình: 4.0 ngày)
  Xe A, Lần 2: 02/10 → 06/10 = 4 ngày
  Xe B, Lần 1: 29/09 → 01/10 = 2 ngày (Trung bình: 2.0 ngày)


💾 AUTO SAVE:
================================================================================

Macro tự động:
- Lưu file mỗi 30 phút
- Tạo folder "Backup_60Phut" cạnh file Excel
- Tên backup: Quan_Ly_Quet_Xe_BACKUP.xlsm
- Mỗi lần backup sẽ overwrite bản cũ
- Status Bar hiển thị: "Auto Save: Lần tiếp theo lúc HH:MM:SS"

Khi đóng file:
- Macro tự động hủy timer
- File được lưu trước khi đóng


⚠️ CÁC LƯU Ý QUAN TRỌNG:
================================================================================

1. ✓ Bảo vệ dữ liệu:
   - Không thể xóa mã xe (cột A) nếu chưa nhập X ở cột F
   - Nhập X ở cột F để cho phép xóa/re-scan

2. ✓ Thời gian quay vòng:
   - Tính từ lần quét TRƯỚC GẦN NHẤT của cùng mã xe
   - Hỗ trợ xe quét xen kẽ (VD: A → B → A)

3. ✓ Từ khóa bẩn:
   - "bẩn" hoặc "ban" hoặc "ko sạch" hoặc "không sạch"
   - Không phân biệt hoa/thường
   - Cần chính xác (VD: "bản" không được, phải "ban")

4. ✓ Trung bình ngày bẩn:
   - Tính: (Tổng ngày bẩn) / (Tổng lần bẩn)
   - Cập nhật tự động khi chạy CapNhatTongHop_Ngay

5. ✓ Backup:
   - Tự động tạo folder Backup_60Phut
   - Giữ 1 bản backup mới nhất


🆘 KHẮC PHỤC SỰ CỰ:
================================================================================

Lỗi: "Macro được vô hiệu hóa"
Giải pháp:
- File → Options → Trust Center → Trust Center Settings
- Macro Settings → Enable all macros (hoặc Trust access to VBA project object model)
- Restart Excel

Lỗi: "Module1 không tìm thấy"
Giải pháp:
- Nhập code lại (xem bước 2.3 - 2.5)

Lỗi: Thời gian quay vòng không tính
Giải pháp:
- Kiểm tra cột B có đúng định dạng thời gian không
- Format: dd/mm/yyyy hh:mm:ss
- Hoặc re-scan mã xe

Auto Save không hoạt động:
Giải pháp:
- Kiểm tra file Excel có lưu dưới dạng .xlsm không
- Bật macro (Enable Macros)
- Kiểm tra Status Bar có hiển thị "Auto Save" không


📞 HỖ TRỢ:
